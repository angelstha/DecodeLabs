Rule-Based AI Chatbot

A simple Rule-Based AI Chatbot developed in Python as Project 1 of the DecodeLabs Artificial Intelligence Internship.

The chatbot uses predefined rules, regular expressions, and conditional logic to recognize user inputs and provide appropriate responses.

📌 Project Overview

This project focuses on the fundamentals of Artificial Intelligence through rule-based decision making rather than machine learning.

The chatbot can:
Respond to greetings
Answer predefined questions
Introduce itself
Explain basic AI concepts
Respond to "thank you"
Handle different greetings such as good morning/evening
Provide a help menu
Give varied responses using random selection
Handle unknown inputs
Exit the conversation using bye

⚙️ How It Works

The chatbot follows a simple rule-based process:

User Input
    ↓
Input Preprocessing
    ↓
Pattern Matching
    ↓
Find Matching Rule
    ↓
Select Response
    ↓
Display Response
    ↓
Continue Conversation

If the chatbot cannot find a matching rule, it provides a fallback response and suggests using the help command.
